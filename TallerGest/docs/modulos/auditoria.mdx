## Cómo se usa
### Revisar la auditoría · Administrador
1. Entra a «Auditoría».
2. Filtra por módulo o por usuario, o usa el buscador.
3. Cada fila indica quién hizo el cambio, sobre qué registro y qué datos cambiaron (valor anterior → valor nuevo). Si se creó un registro, muestra los datos que se agregaron.
4. También quedan los cambios automáticos (estados de las órdenes, descuentos de stock), las fotos y los accesos fallidos.
